# Техническое задание: Улучшение типизации Supabase в проекте CourseAI

## 📋 Текущая ситуация

### Проблемы

1. **Неправильный вывод типов Supabase** - операции `update` и `insert` возвращают тип `never`
2. **Временные решения** - используются `@ts-ignore` директивы с отключением ESLint правил
3. **Ручное обновление типов** - типы генерируются вручную через MCP или CLI
4. **Риск рассинхронизации** - типы могут устареть при изменениях схемы БД

### Текущие костыли

```typescript
// app/courses/actions.ts
// eslint-disable-next-line @typescript-eslint/ban-ts-comment
// @ts-ignore - Supabase type inference issue with update
const { error } = await supabase.from('courses').update({ is_published: !isPublished })
```

## 🎯 Цель

Настроить автоматическую генерацию и правильное использование типов Supabase для обеспечения полной type safety без использования директив подавления ошибок.

## 📝 Задачи

### 1. Настройка автоматической генерации типов

#### 1.1 Локальная генерация

- [ ] Установить Supabase CLI глобально
- [ ] Создать npm скрипт для генерации типов:
  ```json
  {
    "scripts": {
      "types:generate": "supabase gen types typescript --project-id $SUPABASE_PROJECT_ID > types/database.generated.ts",
      "types:check": "tsc --noEmit types/database.generated.ts"
    }
  }
  ```
- [ ] Добавить в `.env.local` переменную `SUPABASE_PROJECT_ID`
- [ ] Документировать процесс в README.md

#### 1.2 CI/CD автоматизация

- [ ] Создать GitHub Action `.github/workflows/generate-types.yml`:
  ```yaml

  on:

      - cron: '0 0 * * *' # Ежедневно
    workflow_dispatch: # Ручной запуск
  ```
- [ ] Настроить автоматический коммит обновленных типов

### 2. Исправление проблем с выводом типов

#### 2.1 Правильная типизация клиентов Supabase

- [ ] Создать типизированные клиенты:

  ```typescript
  // lib/supabase/typed-client.ts
  import { createClient } from '@supabase/supabase-js'
  import { Database } from '@/types/database.generated'

  export const createTypedClient = () => {
    return createClient<Database>(url, key)
  }
  ```

#### 2.2 Создание хелперов для операций

- [ ] Создать типобезопасные обертки для проблемных операций:

  ```typescript
  // lib/supabase/helpers.ts
  import { Database } from '@/types/database.generated'

  type Tables = Database['public']['Tables']
  type CourseUpdate = Tables['courses']['Update']
  type UserFavoriteInsert = Tables['user_favorites']['Insert']

  export async function updateCourse(
    supabase: SupabaseClient<Database>,
    slug: string,
    data: CourseUpdate
  ) {
    return supabase.from('courses').update(data).eq('slug', slug)
  }
  ```

#### 2.3 Миграция существующего кода
