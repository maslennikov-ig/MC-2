# Plan: Fix Stage 4 Document Content Not Passed to LLM Prompts

**Issue**: EMN-1384 - Курс про продажи генерирует контент про деплой/программирование
**Root Cause**: Phase 0.5, Phase 2 не передают содержимое документов в промпты LLM

## Investigation Summary

### What Works Correctly

- **Database**: Documents have correct `processed_content` (про продажи, AMO CRM, билеты)
- **Handler**: Correctly fetches `processed_content` from `file_catalog`
- **Phase 1**: Correctly analyzes documents and outputs:
  - `key_concepts`: ["Воронка продаж", "KPI", "AMO CRM", ...]
  - `determined_topic`: "Продажа билетов на образовательные мероприятия..."

### What Fails

- **Phase 0.5 & Phase 2**: Don't include document content in LLM prompts
- **Phase 2/3 output**: Contains programming content ("Hello World", "Node.js", "deploy")
- **Model xiaomi/mimo-v2-flash**: Ignores `key_concepts` from Phase 1 and hallucinates

### Why It "Worked Before"

This bug existed since Initial Commit. It may have appeared now due to:

1. Different model (xiaomi/mimo-v2-flash vs previous GPT-4o or similar)
2. Topic "Новый курс" is too generic - previous courses had more descriptive titles
3. Model has bias towards programming content

## Problem Analysis

### Symptoms

1. Course with sales documents generates programming content (Node.js, deployment)
2. Clarifying questions are about wrong topic
3. Course title stays as "Новый курс" (default)

### Root Causes Found

| Phase     | File                              | Problem                                                                                  |
| --------- | --------------------------------- | ---------------------------------------------------------------------------------------- |
| Phase 0.5 | `phase-0.5-clarifying.ts:179-204` | `buildCondensedContext()` sends only document stats ("4 total, CORE: 1..."), NOT content |
| Phase 2   | `phase-2-scope.ts:391-393`        | `documentsContext` = "Available Documents: N documents" - NO content                     |
| Phase 1   | Works correctly                   | Receives and processes `document_summaries`, generates correct `determined_topic`        |
| Phase 3   | Works correctly                   | Receives document_summaries as strings and uses them                                     |
| Phase 4   | Works correctly                   | Receives DocumentSummary[] with processed_content                                        |

```

```

```typescript
// Modify buildCondensedContext() to include excerpts:
function buildCondensedContext(
  budgetAllocation: Stage4BudgetAllocation | null,
  documentSummaries?: Array<{ file_name: string; processed_content: string }> | null
): string {
  // ... existing stats ...

  // Add document excerpts (truncated to ~2000 chars each for context)
  if (documentSummaries && documentSummaries.length > 0) {
    const maxCharsPerDoc = Math.floor(8000 / documentSummaries.length);
    contextParts.push('\nDOCUMENT EXCERPTS:');
    documentSummaries.forEach((doc, idx) => {
      const excerpt = doc.processed_content.substring(0, maxCharsPerDoc);
      contextParts.push(`\n[${doc.file_name}]\n${excerpt}${doc.processed_content.length > maxCharsPerDoc ? '...' : ''}`);
    });
  }

  return contextParts.join('\n');
}
```

### Fix 2: Phase 2 - Pass Document Content to Scope Analysis

**File**: `packages/course-gen-platform/src/stages/stage4-analysis/phases/phase-2-scope.ts`

**Change**: Modify `buildPhase2Prompt()` to include actual document content (lines 391-393):

```typescript
// BEFORE (broken):
const documentsContext =
  document_summaries && document_summaries.length > 0
    ? `\n\nAvailable Documents: ${document_summaries.length} documents with processed content`
    : '';

// AFTER (fixed):
const documentsContext =
  document_summaries && document_summaries.length > 0
    ? `\n\nDOCUMENT SUMMARIES (${document_summaries.length} documents, truncated for context):\n${document_summaries
        .map((summary, idx) => {
          const maxChars = Math.floor((25000 * 4) / document_summaries.length); // ~8K tokens per doc
          const truncated =
            summary.length > maxChars
              ? summary.substring(0, maxChars) + '\n[... truncated ...]'
              : summary;
          return `[Document ${idx + 1}]\n${truncated}`;
        })
        .join('\n\n')}`
    : '';
```
