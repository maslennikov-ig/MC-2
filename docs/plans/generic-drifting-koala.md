# Анализ документа "Что продавать" vs. реальные возможности платформы

## Контекст

Отдел маркетинга подготовил документ с 3 продуктовыми пакетами для продажи. Ниже — технический аудит каждого пункта: что реально, что преувеличено, что отсутствует, и что можно добавить.

Обозначения: **РЕАЛЬНО** | **ЧАСТИЧНО** | **НЕ РЕАЛИЗОВАНО** | **ДОБАВИТЬ**

## 1. MEGACAMPUS PILOT (Strategic Entry)

### Аудит знаний

> Анализ текущих «сырых» материалов (скрипты, регламенты, записи звонков) и выявление пробелов.

**ЧАСТИЧНО**

- Загрузка документов (PDF, DOCX, PPTX, TXT) — работает (Stage 1)
- Автоматическая классификация по важности (CORE/IMPORTANT/SUPPLEMENTARY) — работает (Stage 3)
- Создание эмбеддингов и семантический поиск — работает (Stage 2, Qdrant)
- **НО:** "Записи звонков" — аудиофайлы НЕ поддерживаются. Нужна транскрипция вручную
- **НО:** "Выявление пробелов" — нет автоматического gap-анализа. Платформа классифицирует, но не сравнивает с эталонной моделью компетенций

**Рекомендация маркетингу:** Заменить "записи звонков" на "транскрипции звонков". Убрать "выявление пробелов" или переформулировать как "анализ и приоритизация материалов"

### Оцифровка

> Создание эталонного трека обучения (Onboarding Track) с помощью ИИ.

**РЕАЛЬНО**

- 7-стадийный пайплайн генерации курсов — работает
- Педагогический анализ с стратегией обучения (Stage 4) — работает
- Генерация структуры курса с секциями и уроками (Stage 5) — работает
- Генерация контента уроков с RAG (Stage 6) — работает
- Обогащения: обложки, квизы, видео-скрипты, презентации (Stage 7) — работает
- 19 языков поддерживается

**Это можно продавать уверенно.** Это ядро платформы.

### Human-in-the-Loop

> Валидация каждого урока нашими экспертами-методологами

**ЧАСТИЧНО**

- Уточняющие вопросы перед генерацией (clarifying questions) — работает
- Редактирование контента через интерфейс (Lesson Inspector) — работает
- AI-чат для точечной доработки контента (Refinement Chat) — работает
- Одобрение обогащений (draft approval) — работает
- **НО:** Нет формального workflow рецензирования (approve/reject/comment циклы)
- **НО:** Нет ролей "методолог" vs "автор" — только User/Admin/Superadmin

**Рекомендация:** Это скорее наша сервисная обёртка (люди руками проверяют), а не фича платформы. Честно — можно продавать как услугу

### Передача SCORM-пакетов

> Передача готовых SCORM-пакетов и замер метрик эффективности на фокус-группе

**НЕ РЕАЛИЗОВАНО** (критично!)

- SCORM 1.2/2004 экспорт — **НЕТ**
- xAPI экспорт — **НЕТ**
- Есть только: Open edX OLX формат + API-интеграция
- "Замер метрик эффективности" — **НЕТ**. Нет аналитики обучения

**Это серьёзная проблема.** SCORM — стандарт отрасли. Без него PILOT не работает для большинства корпоративных клиентов (WebTutor, iSpring, Mirapolis — все ожидают SCORM).

**Рекомендация:** Либо убрать "SCORM-пакетов" и заменить на "готовых учебных курсов", либо приоритезировать разработку SCORM-экспорта (это реально сделать за 2-4 недели, т.к. SCORM — это HTML+manifest XML)

### Обещание "21 день, сократим адаптацию в 2 раза"

**ЧАСТИЧНО**

- 21 день — реалистично для консалтингового проекта (генерация курса занимает 5-15 мин, основное время — подготовка материалов и валидация)
- "В 2 раза" — нет данных, но генерация ИИ объективно быстрее ручной

## 2. AI CONTENT FACTORY (Scale)

### Потоковая генерация

> Производство курсов, тестов, саммари и тренажеров в промышленных масштабах

**ЧАСТИЧНО**

- Курсы — работает (ядро платформы)
- Тесты (квизы) — работают (Stage 7 enrichments)
- Саммари — работает (Stage 2 суммаризация документов)
- **Тренажёры — НЕТ.** Нет интерактивных симуляций, code playgrounds, или диалоговых тренажёров
- "Промышленные масштабы" — BullMQ с 30 concurrent workers, параллельная генерация. Реально

**Рекомендация:** Убрать "тренажёры". Можно добавить "презентации" (они реально есть)

### SLA 24-48 часов

> Гарантируем готовность курса через 24–48 часов

**РЕАЛЬНО** (с оговоркой)

- Техническая генерация: 5-15 минут
- С обогащениями (картинки, квизы): 30-60 минут
- С human review: 24-48 часов — реалистичный SLA

**Можно продавать.** Технически платформа готова значительно быстрее, но учитывая review — SLA адекватный

### Бесшовная интеграция

> API или выгрузка SCORM 1.2/2004, xAPI (совместимо с WebTutor, iSpring, Mirapolis)

**НЕ РЕАЛИЗОВАНО** (критично!)

- SCORM 1.2 — **НЕТ**
- SCORM 2004 — **НЕТ**
- xAPI — **НЕТ**
- WebTutor совместимость — **НЕТ**
- iSpring совместимость — **НЕТ**
- Mirapolis совместимость — **НЕТ**
- tRPC API — есть, но не REST API для внешних интеграций
- Open edX OLX + API — единственная работающая интеграция

**Это самый опасный пункт документа.** Продавать несуществующие интеграции — репутационный риск.

**Рекомендация:** Заменить на "Интеграция с Open edX" + "Выгрузка в форматах Markdown/HTML". SCORM вынести в roadmap

### Smart Update

> Автоматическое обновление старых курсов при изменении исходных регламентов

**НЕ РЕАЛИЗОВАНО**

- Нет механизма отслеживания изменений в исходных документах
- Нет автоматического пересоздания курсов
- Есть ручная регенерация отдельных уроков (unified-regenerator)

**Рекомендация:** Убрать или пометить как "в разработке". Можно продавать ручное обновление как услугу

## 3. ENTERPRISE PRIVATE CLOUD (Security)

### Изоляция данных / Single-Tenant

> Ваша база знаний физически отделена от внешнего мира

**НЕ РЕАЛИЗОВАНО**

- Текущая архитектура — multi-tenant (Supabase + RLS)
- Single-tenant потребует: отдельный инстанс Supabase, отдельный Qdrant, отдельный Redis
- Docker-compose позволяет self-hosted deployment, но это не "одна кнопка"

**ЧАСТИЧНО ВОЗМОЖНО:** Технически Docker-архитектура позволяет разворачивать отдельные инстансы, но потребуется значительная работа по автоматизации

### Fine-Tuning (Дообучение)

> Настройка нейросети на специфику вашего бизнеса

**НЕ РЕАЛИЗОВАНО** (и вводит в заблуждение)

- Платформа использует внешние LLM через OpenRouter (Gemini, DeepSeek, Qwen и др.)
- Fine-tuning этих моделей НЕ предусмотрен
- Адаптация к бизнесу происходит через RAG (загруженные документы) + промпты, а не через дообучение модели

**Рекомендация:** Заменить "Fine-Tuning (Дообучение)" на "Контекстная адаптация" — "ИИ использует ваши документы как базу знаний и генерирует контент в контексте вашего бизнеса". Это честно и это реально работает

### White Label

> Полное брендирование интерфейса

**НЕ РЕАЛИЗОВАНО**

- Нет системы тем/скинов
- Нет конфигурации логотипа/цветов через интерфейс
- Нет механизма кастомных доменов

**Можно реализовать:** Next.js + Tailwind CSS позволяют добавить theming за 1-2 недели

### Enterprise Security (SSO, AD)

> Интеграция с SSO, Active Directory

**НЕ РЕАЛИЗОВАНО**

- Supabase Auth: email/password + Google/GitHub OAuth
- SAML SSO — **НЕТ**
- LDAP/Active Directory — **НЕТ**
- Расширенное логирование — ЧАСТИЧНО (audit_log, generation_trace)

**Рекомендация:** SSO через SAML можно добавить через Supabase Auth (они поддерживают SAML на платных планах). AD integration — сложнее

### Общая проблема "изолированного контура"

Платформа зависит от внешних сервисов:

- OpenRouter (LLM API) — данные уходят наружу
- Jina (embeddings) — данные уходят наружу
- Supabase Cloud — данные в облаке

Для истинного private cloud нужно:

- Self-hosted LLM (например, vLLM + open-source модели)
- Self-hosted embedding model
- Self-hosted PostgreSQL + Qdrant

**Это возможно, но требует отдельного проекта на 2-3 месяца**

## Что ДОБАВИТЬ (чего нет в документе, но реально работает)

### 1. AI Quality Assurance (уникальное преимущество)

- 3-судейская система оценки качества (CLEV voting)
- Автоматическое исправление ошибок (targeted refinement)
- 5-уровневая каскадная система восстановления
- **Это уникальная фича, которую стоит продавать**

### 2. Интерактивный процесс создания

- Уточняющие вопросы перед генерацией (AI спрашивает, не угадывает)
- Визуализация структуры курса в реальном времени (React Flow граф)
- Редактирование любого элемента через AI-чат
- **Это делает процесс прозрачным и контролируемым**

### 3. Обогащения контента (Stage 7)

- Обложки курсов (AI-генерация изображений)
- Карточки уроков
- Скрипты для видео
- Скрипты для подкастов
- Квизы для проверки знаний
- Презентации
- **6 типов обогащений — больше, чем у конкурентов**

### 4. Многоязычность

- 19 языков, включая CJK (китайский, японский, корейский)
- Генерация курса на любом языке из документов на любом языке
- **Глобальные компании могут обучать сотрудников по всему миру**

### 5. Педагогический дизайн

- Автоматическая классификация сложности
- 3-уровневая маршрутизация моделей по сложности контента
- Стратегия обучения, адаптированная под тему
- **ИИ не просто конвертирует текст — он выстраивает методологию**

## Рекомендуемая структура продуктов (скорректированная)

### PILOT (можно продавать СЕЙЧАС)

- Загрузка ваших документов → AI-анализ и классификация
- Генерация учебного курса с педагогическим дизайном
- Квизы, обложки, скрипты для видео
- Проверка качества 3-судейской AI-системой
- Доработка экспертами (услуга)
- Публикация в Open edX или передача в Markdown/HTML
- **Убрать:** SCORM, замер метрик, записи звонков

### CONTENT FACTORY (можно продавать ЧАСТИЧНО)

- Потоковая генерация курсов (30 параллельных воркеров)
- 19 языков
- 6 типов обогащений
- Интеграция с Open edX
- **Убрать:** SCORM/xAPI/WebTutor/iSpring, Smart Update, тренажёры
- **В roadmap:** SCORM экспорт (2-4 недели), REST API для внешних интеграций

### ENTERPRISE (нельзя продавать сейчас — нужна разработка)

- Требует: self-hosted LLM, SAML SSO, White Label, изоляция данных
- Оценка: 2-3 месяца разработки
- **Можно продавать:** как "Выделенный инстанс" (dedicated) с нашим управлением, но не как "Private Cloud в вашем контуре"
