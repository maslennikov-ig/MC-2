# План: Показывать сгенерированные изображения + возможность перегенерации с кастомным промптом

## Проблема

Сейчас плейсхолдеры для cover/card скрываются после генерации. Пользователь не видит результат и не может перегенерировать.

## Требования пользователя

1. **Показывать ВСЕ типы** (cover, card) всегда - и сгенерированные, и нет
2. **Для перегенерации**: поле ввода для дополнительного промпта (что изменить)
3. **Для первой генерации**: опциональное поле для кастомного промпта (есть дефолтный, но можно ввести свой)
4. **Тултипы**: для каждого поля объяснение что оно делает (использовать существующий компонент)

## Данные

- URL изображения: `lesson_enrichments.content.imageUrl` (JSONB)
- Оригинальный промпт: `lesson_enrichments.content.generation_prompt`
