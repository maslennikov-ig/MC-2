### 5.6 File Processing Flow

```
1. User uploads file via tRPC endpoint (T057)
2. File saved to /uploads/{orgId}/{courseId}/{fileId}.{ext}
3. Metadata in file_catalog (vector_status=pending)
4. BullMQ job created → DOCUMENT_PROCESSING
5. Worker calls MCP client → Docling MCP Server
6. Docling parses document → DoclingDocument JSON
7. Response → Worker → store parsed_content in file_catalog
8. vector_status → indexing
9. Continue to T075 (chunking)
```
