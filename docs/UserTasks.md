Разработать фазу **Generation**, которая генерирует JSON-структуру курса на основе результатов стадии Analyze и данных от клиента. Эта структура служит двойной цели:

## 📊 Входные и выходные данные

### Входные данные

**Источник 1: Стадия Analyze**

- Подробное задание на генерацию
- Структурированная информация о курсе
- Данные из Summary (НЕ полный summary - только из Analyze)

**Источник 3: Векторная БД**

- Все загруженные файлы клиента сохраняются в векторной БД
- Стратегия использования вектора будет определена в отдельной задаче

- Иерархию курса (модули → уроки)
