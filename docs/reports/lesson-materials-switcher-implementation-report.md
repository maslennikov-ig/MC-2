## 4. Known Gaps / Residual Risks & Monitoring

1. **Async Playback URL Fetching:** Because `getEnrichmentPlaybackUrl` executes asynchronously inside `LessonMaterialsSwitcher`'s `useEffect`, there is a brief microsecond window where the player might load without the `src`. We added a state guard to handle it cleanly, but in slow network conditions, the user might see a brief loading state.
2. **Missing Media Types:** The switcher explicitly handles `video`, `audio`, `quiz`, `presentation`, and `document`. If a brand new core enrichment type is introduced in the future (e.g. `interactive_map`), it will need to be explicitly added to `availableTypes` array inside `LessonMaterialsSwitcher` to appear in the top tabs.
3. **Empty Presentation Fallback:** `presentation` slides currently render as a very basic scrolling list of cards if they don't have a dedicated rich player component. We've added a graceful fallback, but building a dedicated visual `PresentationPlayer` component later would improve the UX.
4. **Monitoring Suggestion:** Monitor the Supabase `lesson_enrichments` table for instances of `status = 'completed'` where `content` objects are `null` or missing their required internal schemas (e.g. missing `content.slides` for presentation), which would trigger our fallback read-only text warnings in the UI.
