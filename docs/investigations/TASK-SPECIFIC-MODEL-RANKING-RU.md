## 🎯 Анализ Требований По Задачам

### Задача 1: Генерация МЕТАДАТЫ Курса

**Что требуется:**

- ✨ **Креативность**: Привлекательные описания курса, "продающие" тексты
- 🧠 **Глубина понимания**: Педагогика, Bloom's Taxonomy, learning outcomes
- 📝 **Качество языка**: Особенно русский - эмоциональность, естественность
- 🎨 **Детальность**: Подробные описания целевой аудитории, prerequisites
- 💡 **Инсайты**: Understanding курса от названия, правильные теги
- 🎓 **Педагогическая грамотность**: Assessment strategy, learning outcomes

**Характеристики генерации:**

- Частота: Редко (1 раз на курс)
- Объем: ~1500-2000 токенов
- Критичность: ВЫСОКАЯ (первое впечатление студента)
- Можно пожертвовать скоростью ради качества

---

### Задача 2: Генерация СТРУКТУРЫ УРОКОВ

**Что требуется:**

- 📋 **Структурированность**: Четкая иерархия уроков, логика последовательности
- 🔗 **Когерентность**: Уроки должны плавно переходить друг в друга
- 💪 **Практичность**: Конкретные, выполнимые упражнения (не абстракции)
- 📊 **Детализация**: Key topics, objectives на каждый урок
- ⚡ **Скорость**: Уроков много (3-5 на секцию × много секций)
- 🎯 **Точность JSON**: Сложная вложенная структура, не должно быть ошибок

**Характеристики генерации:**

- Частота: Часто (3-5 уроков на секцию, десятки секций на курс)
- Объем: ~2000-3000 токенов на generation
- Критичность: СРЕДНЯЯ (студент видит после метадаты)
- Скорость важна (масштабируемость)

## 💡 Рекомендуемая Стратегия: Dual-Model Approach

### Вариант 1: Качество Превыше Всего

```
Метадата: qwen3-235b-thinking ($0.08/$0.36)
    ↓
Уроки: deepseek-chat-v3.1 ($0.27/$1.1)
```

**Преимущества:**

- ✨ Максимальное качество метадаты (4400+ токенов)
- 🚀 Хорошая скорость для уроков (13.8s)
- 💰 Qwen3-235b-thinking дешевая для метадаты
- 📊 Отличная структура уроков

**Компромиссы:**

- Две разные модели = более сложная логика
- Нужно переключение между моделями

**Кейс использования:**

- Premium курсы
- Когда метадата КРИТИЧНА для продаж
- Когда нужны детальные, привлекательные описания

**Стоимость на 1 курс (1 метадата + 5 секций × 3 урока = 16 generations):**

- 1 × metadata (qwen3-235b-thinking): ~$0.0018
- 15 × lessons (deepseek-chat-v3.1): ~$0.035
- **Итого: ~$0.037 за курс**

## 💼 Моя Личная Рекомендация

**Для продакшена я бы выбрал Вариант 1:**

```python
# Псевдокод реализации
async def generateCourse(courseTitle):
    # МЕТАДАТА: Используем qwen3-235b-thinking
    metadata = await generateMetadata(
        model="qwen/qwen3-235b-a22b-thinking-2507",
        title=courseTitle
    )
    # Причина: Максимальная детальность, thinking tokens, дешево

    # УРОКИ: Используем deepseek-chat-v3.1
    lessons = await generateLessons(
        model="deepseek/deepseek-chat-v3.1",
        sections=metadata.sections
    )
    # Причина: Отличная структура, практичность, скорость

    return { metadata, lessons }
```

**Почему:**

1. ✨ Метадата - это лицо курса, нужна максимальная детальность
2. 🚀 Уроков много, нужна хорошая скорость
3. 💰 Суммарная стоимость адекватная ($0.037/курс)
4. 🎯 Каждая модель делает то, что у нее лучше всего получается
5. 📈 Масштабируется (deepseek-chat быстрая для уроков)

**Fallback стратегия:**

- Если qwen3-235b-thinking не доступна → используем kimi-k2-thinking
- Если deepseek-chat-v3.1 не доступна → используем deepseek-v3.2-exp

## 🔍 Дополнительные Инсайты

### Почему НЕ использовать одну модель везде?

**Проблема thinking models для уроков:**

- Медленные (35s vs 13.8s)
- При генерации 50 уроков: 1750s vs 690s (разница 17 минут!)
- Дороже без значительного улучшения качества структуры

**Проблема fast models для метадаты:**

- Менее детальные описания
- Метадата генерируется редко - можно пожертвовать скоростью
- Первое впечатление студента - критично
