## Где мы сейчас

MegaCampusAI — это полноценная платформа генерации образовательных курсов с 7-стадийным AI-конвейером, системой судей, 13 типами контента и поддержкой 19 языков. Стоимость генерации одного курса < $1, время — 3-8 минут.

Но генерация курсов — это **точка входа**, а не конечная цель.

### Как это работает

**1. Сбор новых знаний от сотрудников**

Сотрудники регулярно отвечают на вопрос: _"Какие новые знания вы получили за последнее время?"_ — через короткие опросы, интегрированные в рабочий поток (Telegram, Slack, веб-интерфейс).

**2. Верификация руководителем**

Каждый фрагмент нового знания проходит через ревью руководителя: _"Это действительно так? Это полезно для команды?"_. Только подтверждённые знания попадают в обучение.

**3. Автоматическое расширение курсов**

Верифицированные знания автоматически генерируют новые обучающие блоки через тот же 7-стадийный AI-конвейер MegaCampusAI — с квизами, флеш-картами и привязкой к существующим курсам.

**4. Персонализированная доставка**

Каждый сотрудник получает тот контент, который ему действительно нужен — на основе его роли, пробелов в знаниях и карьерных целей.

### Результат

Обучение, которое **не устаревает**, потому что постоянно обновляется реальными знаниями из самой компании. Каждый сотрудник — одновременно ученик и источник знаний.

## Phase 3: AI Tutor — Персональный наставник

### Проблема двух сигм (Bloom's 2 Sigma Problem)

В 1984 году Бенджамин Блум опубликовал исследование, которое стало одним из самых цитируемых в педагогике:

> _"The average tutored student was above 98% of the students in the control class."_
>
> — Bloom, B. S. (1984). _The 2 Sigma Problem: The Search for Methods of Group Instruction as Effective as One-to-One Tutoring._ Educational Researcher, 13(6), 4-16.

**Ключевой вывод**: студент с персональным тьютором показывает результаты **на 2 стандартных отклонения** (2 сигмы) выше, чем студент в обычном классе. Это разница между оценками C и A. Около 90% студентов с тьютором достигают уровня, которого достигают лишь 20% лучших студентов в обычном классе.

**Проблема**: индивидуальный тьютор для каждого — слишком дорого для любой организации.

**Наше решение**: AI-тьютор, который знает всё о сотруднике и обладает всей базой знаний компании.

### Как будет работать AI Tutor

```
  ┌─────────────────────────────────────────────────────┐
  │                    AI TUTOR                          │
  │                                                      │
  │  Знает о сотруднике:          Знает о компании:     │
  │  ├─ Роль и обязанности       ├─ Все курсы           │
  │  ├─ Пройденные курсы         ├─ Все документы       │
  │  ├─ Результаты квизов        ├─ Верифицированные    │
  │  ├─ Проседающие темы         │  знания сотрудников  │
  │  ├─ Карьерные цели           ├─ Регламенты и        │
  │  ├─ Стиль обучения           │  процедуры           │
  │  └─ История взаимодействий   └─ Лучшие практики     │
  │                                                      │
  │  Может:                                              │
  │  ├─ Составить индивидуальный план обучения          │
  │  ├─ Подобрать контент под пробелы в знаниях         │
  │  ├─ Ответить на вопросы по теме урока               │
  │  ├─ Предложить дополнительные материалы             │
  │  ├─ Помочь с карьерным развитием                    │
  │  └─ Адаптировать сложность под уровень              │
  └─────────────────────────────────────────────────────┘
```

### Персонализация обучения

| Аспект         | Как персонализируется                                                                     |
| -------------- | ----------------------------------------------------------------------------------------- |
| **Содержание** | Только то, чего сотруднику не хватает — на основе результатов квизов и оценок             |
| **Сложность**  | Адаптивная: если тема даётся легко — ускоряемся, если сложно — углубляемся                |
| **Формат**     | Предпочтительный стиль обучения (визуальный, аудио, текстовый, практический)              |
| **Темп**       | Учёт загруженности: больше контента в спокойные дни, меньше — в пиковые                   |
| **Карьера**    | Контент выстроен в сторону карьерных целей сотрудника (определяются совместно с тьютором) |

### Решение "Проблемы двух сигм" через AI

Bloom показал, что тьютор даёт +2σ. Мы строим AI-тьютора, который:

- **Масштабируется** — один на каждого сотрудника, без ограничений
- **Не устаёт** — доступен 24/7
- **Знает всё** — интегрирован со всей базой знаний компании
- **Помнит всё** — полная история взаимодействий и прогресса
- **Постоянно улучшается** — новые знания от сотрудников → новый контент для обучения

## Phase 4: Corporate Knowledge Graph

### От курсов — к полной карте знаний компании

По мере накопления курсов, знаний от сотрудников и ревью от руководителей формируется **корпоративный граф знаний** — единая, живая карта всего, что знает компания.

### Источники знаний

```
  ┌──────────────────────────────────────────────────┐
  │           CORPORATE KNOWLEDGE GRAPH               │
  │                                                    │
  │  Sources:                                          │
  │  ├─ Образовательные курсы (MegaCampusAI)          │
  │  ├─ Знания сотрудников (опросы + верификация)     │
  │  ├─ Документы компании (регламенты, политики)     │
  │  ├─ Планёрки и совещания (транскрипты)            │
  │  ├─ Корпоративные чаты (Slack, Telegram)          │
  │  ├─ Отраслевые стандарты и регуляции              │
  │  └─ Внешние источники (отраслевые новости, рынок) │
  │                                                    │
  │  Capabilities:                                     │
  │  ├─ Семантический поиск по всей базе знаний       │
  │  ├─ "Что мы решили по этому вопросу?"             │
  │  ├─ "Кто в компании эксперт в этой области?"      │
  │  ├─ Автоматическая актуализация обучения          │
  │  ├─ Сохранение экспертизы уходящих сотрудников    │
  │  └─ Мониторинг соблюдения регламентов             │
  └──────────────────────────────────────────────────┘
```

### Ghost SME: сохранение знаний уходящих экспертов

Когда ключевой сотрудник покидает компанию, его экспертиза обычно уходит вместе с ним. В нашей системе все его знания — ответы на вопросы, ревью, созданные материалы — сохраняются в графе знаний и остаются доступны команде.

### Living Documents: самообновляющиеся регламенты

Регламенты и процедуры автоматически обновляются на основе решений, принятых на совещаниях. Если на планёрке решили изменить процесс — система обнаруживает это и предлагает обновить соответствующий документ.

## Конкурентные преимущества стратегии

### 1. Естественная точка входа

Генерация курсов — понятная, конкретная ценность. Компания начинает с курсов, затем расширяет использование на всю базу знаний. Каждый новый курс — это данные для Knowledge Graph.

### 2. Технологический задел

Всё, что уже построено в MegaCampusAI, напрямую переиспользуется:

- **RAG + Reranking** → поиск по корпоративным знаниям
- **LLM Routing (20+ моделей)** → AI-агенты для разных задач
- **Judge System** → валидация знаний сотрудников
- **Multi-tenant RLS** → изоляция данных между компаниями
- **7-Stage Pipeline** → генерация обучающего контента из любых источников

### 3. Data Flywheel с первого дня

Каждый курс, каждый ответ на квиз, каждое знание от сотрудника — всё это обогащает граф знаний. Чем дольше компания использует платформу, тем ценнее она становится.

### 4. Проблема двух сигм как драйвер

Bloom доказал, что тьютор даёт +2σ. Мы строим масштабируемого AI-тьютора на основе реальных знаний конкретной компании — это не абстрактный ChatGPT, а наставник, который знает контекст.

### 5. Окно возможности

Категория "AI Operating System for Business" **ещё не занята**. Gong владеет "Revenue AI OS" (вертикаль), Palantir — "Enterprise AI OS" (крупный бизнес). Ближайшие 12-18 месяцев — оптимальное время для создания категории до начала консолидации рынка.

## Compliance & Security by Design

| Требование             | Реализация                                                                             |
| ---------------------- | -------------------------------------------------------------------------------------- |
| **GDPR Article 22**    | Human-in-the-loop обязательный — никакие AI-решения не применяются автоматически       |
| **EU AI Act**          | Прозрачность: каждый вывод AI сопровождается точной цитатой из источника               |
| **Anti-hallucination** | Каждое утверждение привязано к `sourceQuote` — точной цитате из документа              |
| **Data Isolation**     | Row-Level Security на уровне PostgreSQL, изоляция между организациями                  |
| **Audit Trail**        | Полная история: кто одобрил, кто изменил, когда, какая версия модели                   |
| **Right to Erasure**   | Криптографическое удаление по запросу в течение 30 дней                                |
| **Process-not-People** | Система анализирует процессы, не людей ("Процесс заблокирован", не "Сотрудник плохой") |
