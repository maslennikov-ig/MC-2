## Phase 0.5: Уточняющие вопросы

### Что это?

Новая фаза внутри Stage 4, которая генерирует умные вопросы на основе загруженных документов перед началом анализа. Позволяет уточнить предпочтения пользователя.

### Где находится?

- **Граф генерации**: Отдельная нода-ответвление вниз от Stage 4
- **Inspector Panel**: Панель с вопросами при клике на Stage 4 в статусе `stage_4_clarifying`

### Тест-кейсы

#### TC-1: Появление уточняющих вопросов

**Предусловия**: Курс со загруженными документами (минимум 1 файл)

| Шаг | Действие                  | Ожидаемый результат                              |
| --- | ------------------------- | ------------------------------------------------ |
| 1   | Запустить генерацию курса | Stage 1-3 проходят                               |
| 2   | Дождаться Stage 4         | Статус меняется на `stage_4_clarifying`          |
| 3   | Наблюдать граф            | Появляется нода "Уточняющие вопросы" под Stage 4 |
| 4   | Кликнуть на ноду Stage 4  | Открывается панель ClarifyingPanel               |
| 5   | Проверить вопросы         | Отображаются 3-7 вопросов с приоритетами         |

#### TC-2: Приоритеты вопросов

| Шаг | Действие                       | Ожидаемый результат                                                |
| --- | ------------------------------ | ------------------------------------------------------------------ |
| 1   | Открыть ClarifyingPanel        | Видны вопросы с разными приоритетами                               |
| 2   | Проверить Critical (красный)   | Badge "ОБЯЗАТЕЛЬНЫЙ", красная левая граница                        |
| 3   | Проверить Important (желтый)   | Badge "ВАЖНЫЙ", amber левая граница                                |
| 4   | Проверить Nice-to-have (серый) | Badge "ЖЕЛАТЕЛЬНЫЙ", серая пунктирная граница, кнопка "Пропустить" |

#### TC-3: Ответ на вопрос (Suggested)

| Шаг | Действие                              | Ожидаемый результат                                 |
| --- | ------------------------------------- | --------------------------------------------------- |
| 1   | Найти вопрос с предложенными ответами | Видны 2-4 варианта ответа                           |
| 2   | Кликнуть на вариант                   | Вариант подсвечивается зелёным, появляется галочка  |
| 3   | Проверить progress bar                | Процент увеличивается                               |
| 4   | Auto-scroll                           | Экран скроллится к следующему неотвеченному вопросу |

#### TC-4: Ответ на вопрос (Custom)

| Шаг | Действие                      | Ожидаемый результат           |
| --- | ----------------------------- | ----------------------------- |
| 1   | Найти блок "Свой вариант"     | Есть textarea                 |
| 2   | Ввести текст менее 3 символов | Кнопка "Сохранить" неактивна  |
| 3   | Ввести текст 3+ символов      | Кнопка "Сохранить" активна    |
| 4   | Сохранить                     | Вопрос отмечен как отвеченный |

#### TC-5: Пропуск вопроса

| Шаг | Действие                  | Ожидаемый результат                                |
| --- | ------------------------- | -------------------------------------------------- |
| 1   | Найти Critical вопрос     | Нет кнопки "Пропустить"                            |
| 2   | Найти Important вопрос    | Нет кнопки "Пропустить"                            |
| 3   | Найти Nice-to-have вопрос | Есть кнопка "Пропустить"                           |
| 4   | Кликнуть "Пропустить"     | Вопрос отмечен как skipped, progress увеличивается |

#### TC-6: Принять все рекомендации

| Шаг | Действие                            | Ожидаемый результат                               |
| --- | ----------------------------------- | ------------------------------------------------- |
| 1   | Кликнуть "Принять все рекомендации" | Все вопросы получают первый suggested ответ       |
| 2   | Наблюдать за процессом              | Ответы сохраняются последовательно (не все сразу) |
| 3   | Дождаться завершения                | Progress = 100%, появляется confetti              |

#### TC-7: Продолжение генерации

| Шаг | Действие                         | Ожидаемый результат                               |
| --- | -------------------------------- | ------------------------------------------------- |
| 1   | Ответить на все Critical вопросы | Кнопка "Продолжить генерацию" становится активной |
| 2   | Не отвечать на Critical          | Кнопка неактивна (opacity 50%)                    |
| 3   | Кликнуть "Продолжить"            | Статус меняется на `stage_4_analyzing`            |
| 4   | Наблюдать Stage 4                | Продолжается анализ документов                    |

#### TC-8: Обработка ошибок

| Шаг | Действие                | Ожидаемый результат                           |
| --- | ----------------------- | --------------------------------------------- |
| 1   | Симулировать offline    | Попытаться ответить на вопрос                 |
| 2   | Проверить UI            | Появляется toast "Не удалось сохранить ответ" |
| 3   | Восстановить соединение | Можно повторить попытку                       |

## Chat: Общение с моделью

### Что изменилось?

1. **Обязательный выбор intent** перед отправкой сообщения
2. **Inline editing** для Stage 6 (редактирование прямо в тексте)
3. **Cascade deletion** при удалении стадии
4. **Исправлены 401/404 ошибки** авторизации

### Где находится?

- **GlobalCourseChat**: Правая панель на странице генерации курса
- **Inline Editor**: Клик на текст урока в Stage 6

### Тест-кейсы

#### TC-9: Обязательный выбор Intent

| Шаг | Действие                           | Ожидаемый результат                    |
| --- | ---------------------------------- | -------------------------------------- |
| 1   | Открыть чат курса                  | Видно поле ввода сообщения             |
| 2   | Ввести текст без выбора intent     | Кнопка "Отправить" неактивна           |
| 3   | Выбрать intent (edit/question/etc) | Кнопка "Отправить" становится активной |
| 4   | Отправить сообщение                | Сообщение уходит с выбранным intent    |

#### TC-10: Stage 6 Inline Editing

**Предусловия**: Курс достиг Stage 6, есть сгенерированные уроки

| Шаг | Действие               | Ожидаемый результат        |
| --- | ---------------------- | -------------------------- |
| 1   | Открыть урок в Stage 6 | Видно содержимое урока     |
| 2   | Кликнуть на текст      | Появляется inline editor   |
| 3   | Отредактировать текст  | Текст изменяется           |
| 4   | Сохранить              | Изменения сохраняются в БД |
| 5   | Обновить страницу      | Изменения сохранены        |

#### TC-11: Cascade Stage Deletion

| Шаг | Действие                             | Ожидаемый результат                            |
| --- | ------------------------------------ | ---------------------------------------------- |
| 1   | Открыть курс с пройденными Stage 4-6 | Видны результаты всех стадий                   |
| 2   | Удалить документ из Stage 3          | Появляется предупреждение о каскадном удалении |
| 3   | Подтвердить удаление                 | Stage 4, 5, 6 данные удаляются                 |
| 4   | Проверить статус                     | Курс возвращается к `stage_3_*`                |

#### TC-12: Chat Авторизация

| Шаг | Действие            | Ожидаемый результат             |
| --- | ------------------- | ------------------------------- |
| 1   | Открыть чат курса   | Нет 401 ошибок в консоли        |
| 2   | Отправить сообщение | Сообщение доставляется, нет 404 |
| 3   | Обновить страницу   | История чата загружается        |

## Регрессионное тестирование

### Критические пути

| #   | Путь                                                    | Статус |
| --- | ------------------------------------------------------- | ------ |
| R-1 | Создание курса → загрузка документов → запуск генерации | ☐      |
| R-2 | Stage 1-3 проходят без ошибок                           | ☐      |
| R-3 | Stage 4 анализ документов                               | ☐      |
| R-4 | Stage 5 генерация структуры                             | ☐      |
| R-5 | Stage 6 генерация контента                              | ☐      |
| R-6 | Stage 7 публикация                                      | ☐      |
| R-7 | Просмотр опубликованного курса                          | ☐      |

### Проверка безопасности

| #   | Проверка                                          | Статус                      |
| --- | ------------------------------------------------- | --------------------------- |
| S-1 | XSS: вставить `<script>alert(1)</script>` в ответ | ☐ Должен быть санитизирован |
| S-2 | CSRF: проверить X-CSRF-Token в Network tab        | ☐ Должен присутствовать     |
| S-3 | Rate limiting: быстро отправить 10 ответов        | ☐ Должен замедлиться        |

## Известные ограничения

1. **Второй раунд вопросов** - функционал готов, но UI кнопка скрыта
2. **Max 2 раунда** - больше итераций не поддерживается
3. **Timeout 60s** - LLM вызов прерывается через 60 секунд
