### Продукт 3: ENTERPRISE PRIVATE CLOUD — разбор по пунктам

#### Изоляция данных / Single-Tenant

> «Ваша база знаний физически отделена от внешнего мира и других клиентов»

❌ **Не реализовано в текущем виде**

- Архитектура — multi-tenant (PostgreSQL + Row-Level Security)
- Single-tenant потребует: отдельный инстанс БД, отдельный Qdrant, отдельный Redis
- Docker-архитектура позволяет развернуть отдельный инстанс, но это не автоматизировано

**Важный нюанс:** Даже при выделенном инстансе платформа зависит от внешних сервисов:

- OpenRouter (LLM API) — запросы и данные уходят на внешние серверы
- Jina (embeddings) — аналогично
- Для истинного «изолированного контура» нужны self-hosted LLM (vLLM + open-source модели) и self-hosted embedding — это отдельный проект на 2-3 месяца

#### Fine-Tuning (Дообучение)

> «Настройка нейросети на специфику вашего бизнеса, сленг, аббревиатуры»

❌ **Не реализовано, и формулировка вводит в заблуждение**

- Платформа использует внешние LLM через OpenRouter (Gemini, DeepSeek, Qwen, и др.)
- Fine-tuning (дообучение моделей) не предусмотрено и не планируется
- Адаптация к бизнесу реально происходит через RAG: ИИ опирается на загруженные документы компании и генерирует контент в их контексте

**Рекомендация:** Заменить «Fine-Tuning (Дообучение)» на **«Контекстная адаптация»** — «ИИ использует ваши внутренние документы как базу знаний и генерирует курсы в контексте вашего бизнеса, с вашей терминологией и спецификой». Это честно, и это реально работает

#### White Label

> «Полное брендирование интерфейса, корпоративный домен»

❌ **Не реализовано**

- Нет системы тем / скинов
- Нет конфигурации логотипа и цветов через интерфейс
- Нет кастомных доменов

**Оценка реализации:** Next.js + Tailwind CSS позволяют добавить базовый theming (логотип, цвета, шрифты) за 1-2 недели

#### Enterprise Security (SSO, Active Directory)

> «Интеграция с корпоративными каталогами (SSO, Active Directory)»

| Заявление               | Статус      | Детали                                                                             |
| ----------------------- | ----------- | ---------------------------------------------------------------------------------- |
| SSO (SAML)              | ❌ Нет      | Не реализовано. Supabase Auth поддерживает SAML на платных планах — можно добавить |
| Active Directory / LDAP | ❌ Нет      | Не реализовано, сложнее в интеграции                                               |
| Расширенное логирование | ⚠️ Частично | Есть audit_log, generation_trace, fsm_events. Нет SIEM-интеграции                  |

### Что не упомянуто в документе, но является реальным конкурентным преимуществом

Рекомендуем добавить в маркетинговые материалы:

**1. AI Quality Assurance (3 судьи)**
Каждый сгенерированный урок проходит проверку системой из 3 независимых AI-судей (CLEV voting). При обнаружении проблем — автоматическое точечное исправление конкретных параграфов, а не перегенерация с нуля. 5-уровневая каскадная система восстановления при ошибках. Это уникальная фича, которой нет у конкурентов.

**2. Интерактивный процесс (а не «чёрный ящик»)**

- Перед генерацией ИИ задаёт уточняющие вопросы (не угадывает, а спрашивает)
- Визуальный граф структуры курса в реальном времени (можно контролировать процесс)
- AI-чат для точечной доработки любого фрагмента после генерации
- Прозрачность: клиент видит, что происходит на каждом этапе

**3. 6 типов обогащений**
Помимо текста курса, платформа автоматически генерирует: обложки (AI-картинки), карточки уроков, скрипты для видео, скрипты для подкастов, квизы для проверки знаний, презентации. Это больше, чем у большинства конкурентов.

**4. 19 языков**
Поддержка генерации курсов на 19 языках, включая русский, английский, китайский, японский, корейский, арабский, хинди. Документы на одном языке — курс на другом. Актуально для глобальных компаний.

**5. Педагогический дизайн, а не конвертация**
ИИ не просто конвертирует текст в формат урока. Он анализирует тему, выстраивает стратегию обучения, классифицирует сложность материала и адаптирует подачу. 3-уровневая маршрутизация: простые темы обрабатываются быстрыми моделями, сложные — премиальными.
