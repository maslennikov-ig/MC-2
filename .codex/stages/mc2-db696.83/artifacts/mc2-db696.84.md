Hardened the Stage 2 Jina embedding path used by Career Playbook course bridge documents.

The late-chunking request payload now sends `truncate: true`, matching the defensive behavior of the other Jina client path. If Jina still rejects a batch with a late-chunking/token-window 422, the request path recursively splits the batch and retries smaller halves while preserving the truncation flag.
