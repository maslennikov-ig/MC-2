# Summary

Phase 6 now accepts an explicit title-language mode. Career Playbook supplies `ru` or `en` from its
job, or the explicit `document` mode for other supported playbook languages. Because the option is
present, Phase 6 never queries `courses` with a playbook id.

# Scope / Routing

The default option remains absent for ordinary course processing, so its stored course-language
lookup and fallback behavior are unchanged. Document-language metadata still comes from the source
text rather than the title-language preference.

# Verification

The first focused unit run failed because the Career Playbook call contained only `onProgress`.
After the change it includes `titleLanguage: 'ru'`; all three focused source-processing tests,
focused lint, the monorepo type-check, and the production build pass.

# Delivery / Cleanup

Accepted in the primary `develop` worktree. No delegated branch or child worktree exists.

# Risks / Follow-ups / Explicit Defers

Title prompts currently distinguish Russian from English. Other Career Playbook languages therefore
use detected source language as the existing neutral fallback rather than being mislabeled as a
course lookup failure.
