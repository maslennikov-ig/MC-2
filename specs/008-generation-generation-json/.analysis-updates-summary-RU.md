### 3. Переполнение RAG контекста (U3 - СРЕДНИЙ ПРИОРИТЕТ)

**Проблема**: FR-004 говорит "RAG context capped at 40K", но не описано, что делать при переполнении.

**Решение**: Добавлена детальная стратегия обрезки в T022.

**Изменённые файлы**:

- **ОБНОВЛЁН**: `tasks.md` T022 — добавлена секция "Overflow handling"

**Логика обработки**:

```markdown
- **Overflow handling** (если топ-5 чанков >40K токенов):
  - Обрезать до первых 40K токенов (приоритет высокоранжированным чанкам по cosine similarity)
  - Логировать: { ragTokens: actualSize, cappedTo: 40000, chunksIncluded: N, chunksTotal: 5 }
  - Обоснование: Топ-ранжированные чанки уже отобраны по релевантности Qdrant
```

**Динамическая корректировка**:

```typescript
const maxRAG = 90000 - (baseTokens + styleTokens + analyzeTokens + sectionTokens);
ragTokens = Math.min(ragTokens, Math.max(0, maxRAG));
```
