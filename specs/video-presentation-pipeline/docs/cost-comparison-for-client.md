# Стоимость генерации видео-презентаций для курсов

## Что мы создаём?

Система автоматической генерации видео-уроков из текстового контента курса.

> **Базовые параметры расчёта:**
> - **1 курс = 80 уроков** (видео-презентаций)
> - **Длительность урока:** 5-8 минут (в среднем 6.5 мин)
> - **Общая длительность курса:** ~8.5 часов видео

**Формат видео:**
```
┌────────────────────────────────────────────────────────────────┐
│  ВСТУПЛЕНИЕ (15 сек)     │  ОСНОВНОЙ КОНТЕНТ (5-45 мин)       │
│  ────────────────────    │  ──────────────────────────────    │
│  AI-ведущий приветствует │  Слайды + код + озвучка            │
│  и представляет тему     │  тем же голосом                    │
└────────────────────────────────────────────────────────────────┘
```

| Компонент | Стоимость | За что платим |
|-----------|-----------|---------------|
| HeyGen/Synthesia | $5,000-20,000/мес | Генерация AI-ведущего |
| Готовая платформа | $500-2,000/мес | Хостинг и доставка видео |

**Стоимость за курс (80 уроков):**
- **$800-2,000+ за курс**
- **$10-25 за урок**

**Плюсы:**
- Минимум разработки
- Высокое качество "из коробки"

**Минусы:**
- Очень дорого при масштабировании
- Зависимость от внешнего сервиса
- Ограничения по кастомизации

## Стоимость при генерации на разных языках

Один и тот же курс можно сгенерировать на нескольких языках. Озвучка и AI-ведущий генерируются заново для каждого языка.

**Пример: курс из 80 уроков на 5 языках (400 видео)**

| Вариант | 1 язык | 5 языков | 10 языков | 19 языков |
|---------|--------|----------|-----------|-----------|
| **Премиум** | $16-20 | $70-90 | $140-180 | $260-340 |
| **Оптимальный** | $4-5 | $18-23 | $36-45 | $70-90 |
| **Бюджетный** | $2.50-3 | $11-14 | $22-28 | $42-55 |

## Визуальная разница между вариантами

### Премиум вариант (с анимациями)

**Переходы между слайдами:**
```
Слайд 1 ──плавно растворяется──► Слайд 2 выплывает справа
```

**Появление списков** (например, "5 правил успешных продаж"):
```
Диктор: "Первое правило — слушайте клиента"
  ✓ Слушайте клиента     ← появляется с анимацией

Диктор: "Второе — задавайте вопросы"
  ✓ Слушайте клиента
  ✓ Задавайте вопросы    ← появляется в этот момент

Диктор: "И третье — предлагайте решение"
  ✓ Слушайте клиента
  ✓ Задавайте вопросы
  ✓ Предлагайте решение  ← появляется синхронно с речью
```

**Появление текста на слайде:**
```
Диктор говорит: "Ключевой ингредиент — это свежий базилик"
На экране: "Ключевой ингредиент" ← появляется
           "свежий базилик"      ← появляется с акцентом (крупнее/ярче)
```

**Схемы и диаграммы:**
```
Диктор: "Процесс состоит из трёх этапов"
  [Этап 1] ← появляется
      ↓    ← появляется стрелка
  [Этап 2] ← появляется
      ↓
  [Этап 3] ← появляется последним
```

---

### Оптимальный/Бюджетный вариант (без анимаций)

**Переходы между слайдами:**
```
Слайд 1 ──мгновенная смена──► Слайд 2
```
Или простое затемнение без движения.

**Появление списков:**
```
Диктор начинает говорить, а на экране сразу видно:
  • Слушайте клиента      ┐
  • Задавайте вопросы     ├── всё показано сразу
  • Предлагайте решение   ┘
```

**Появление текста:**
```
Весь текст слайда виден сразу с начала, пока диктор его озвучивает.
```

**Схемы и диаграммы:**
```
Вся схема видна сразу целиком:
  [Этап 1] → [Этап 2] → [Этап 3]
```

| Элемент | Премиум (с анимациями) | Оптимальный (без анимаций) |

### Когда важны анимации?

**Анимации полезны для:**
- Сложные темы с многоэтапными процессами (продажи, управление, методологии)
- Курсы с большим количеством списков и схем
- Премиум-продукты с высокими ожиданиями качества

**Анимации менее важны для:**
- Простые информационные курсы
- Курсы, где важнее содержание, чем подача
- Внутреннее корпоративное обучение

## Что влияет на качество видео?

### AI-ведущий (аватар)
- **С ведущим:** Видео выглядит более персонализированным, студенты лучше вовлекаются. Во вступлении (15 секунд) появляется виртуальный ведущий, который приветствует и представляет тему урока.
- **Без ведущего:** Видео начинается сразу со слайдов и озвучки — работает, но менее engaging.

### Глобальный CDN
- **С CDN:** Видео загружается быстро в любой стране мира (Европа, Азия, США)
- **Без CDN:** Для локальной аудитории (Россия, СНГ) разницы практически нет. Если основная аудитория в одном регионе — CDN не нужен.

## Ответы на частые вопросы

### Почему не использовать готовые решения типа HeyGen?

При масштабе 100+ видео в день коммерческие решения стоят $5,000-20,000 в месяц. Собственная система окупается за 1-2 месяца работы.

### Можно ли потом добавить анимации?

Да. Архитектура модульная — можно заменить генератор слайдов с простого на анимированный без переделки всей системы.

### Что если Azure или другой сервис упадёт?

Система спроектирована с автоматическими повторами и резервными вариантами. Если AI-ведущий не сгенерировался — видео всё равно создастся, просто без вступления.

### Какое качество озвучки?

Azure TTS — один из лучших синтезаторов речи. Поддерживает 19 языков с естественным звучанием. Для русского и английского качество практически неотличимо от человека.
